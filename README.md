# Student Number Theory Seminar: Endoscopy

Static website for the 2026–27 student reading seminar on endoscopy for SL(2).

This repository contains the seminar homepage (`index.html`), detailed reading assignments (`talks.html`), styling (`style.css`), and draft abstracts (`abstracts.html`, not currently linked from the schedule). No build step is required.

## GitHub Pages

Publish from the `main` branch and the repository's `/ (root)` directory using **Settings → Pages → Build and deployment → Deploy from a branch**. The resulting project site will be available at `https://haotian-zhao.github.io/endoscopy-seminar/` if the repository is created under `haotian-zhao` with the name `endoscopy-seminar`.

Relative links and CSS paths work both on the GitHub Pages project path and the existing seminar site. To update the seminar program, edit `index.html` and `talks.html` and push to `main`.
